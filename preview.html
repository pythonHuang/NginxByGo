🚀 NginxGo

使用 Go 语言重构的高性能 Web 服务器

Version 0.1.0

⚡ 高性能

基于 Go 语言的并发模型，充分利用多核处理器，支持高并发连接。

🔄 Master-Worker 架构

继承 Nginx 的进程模型，Master 进程管理配置，Worker 进程处理请求。

📁 静态文件服务

支持静态文件服务，包含 ETag、Last-Modified 缓存优化。

🌐 反向代理

支持上游服务器转发，实现负载均衡和故障转移。

⚖️ 负载均衡

支持轮询和最少连接两种负载均衡策略。

📦 Gzip 压缩

支持响应内容压缩，减少传输带宽。
