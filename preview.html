🚀 NginxGo

使用 Go 语言重构的高性能 Web 服务器

v0.1.0 · 开发中
⚡

高性能

基于 Go 语言的并发模型，原生支持高并发连接，继承 Nginx 的事件驱动架构。

🏗️

Master-Worker

Master 进程负责配置管理和进程调度，Worker 进程处理实际请求，保障稳定性。

📁

静态文件服务

支持 ETag、Last-Modified 缓存头，支持 MIME 类型自动识别，Gzip 压缩传输。

🌐

反向代理

支持上游服务器转发，X-Real-IP、X-Forwarded-For 头传递。

⚖️

负载均衡

支持轮询 (Round Robin) 和最少连接 (Least Connections) 两种策略。

📝

配置解析

兼容 Nginx 配置文件格式，支持 include、嵌套作用域等特性。

📈 开发进度

🖥️ 快速开始

# 1. 克隆项目 git clone https://github.com/nginxgo/nginxgo.git cd nginxgo # 2. 编译 go build -o nginxgo.exe ./cmd/nginxgo # 3. 运行 ./nginxgo.exe -c conf/nginx.conf # 4. 测试 curl http://localhost:80/

📂 项目结构

nginxgo/ ├── cmd/ │ └── nginxgo/main.go # 程序入口 ├── pkg/ │ ├── core/ # 核心模块 │ ├── config/ # 配置解析 │ ├── http/ # HTTP 服务器 │ │ ├── handler/ # 处理器 │ │ └── filter/ # 过滤器 │ ├── upstream/ # 负载均衡 │ ├── event/ # 事件循环 │ └── log/ # 日志系统 ├── conf/ │ └── nginx.conf # 配置文件 ├── html/ # 静态文件 └── go.mod

🛠️ 技术栈

Go 1.21+ epoll (Linux) kqueue (macOS) IOCP (Windows) Master-Worker HTTP/1.1 Gzip WebSocket (规划中)
